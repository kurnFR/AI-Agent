It will describe how we build Aegis.


Build one feature at a time.
Never break working public APIs.
Compile before integration.
Test before commit.
Refactor only when it delivers measurable value.
Every milestone must be stable before moving on.
Every feature requires a corresponding test.

This becomes the "constitution" of the project. Whenever we face a design choice in six months, we can refer back to these principles instead of debating from scratch.
